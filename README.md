## 📌 Projects

### 📊 [Desinformations-Risiko-Dashboard](https://github.com/jeorgesilva/hot-topics-dashboard)

NLP-basiertes Monitoring-Dashboard zur Identifikation von Desinformationsrisiken und Trendthemen im DACH-Medienraum mittels semantischer Analyse und Embeddings.
**Stack:** Python, spaCy, HuggingFace, sentence-transformers, Scikit-Learn, Streamlit, SQLite.

### 📚 [RAG-gestützter KI-Tutor (Teacher_Isa)](https://github.com/jeorgesilva/Teacher_Isa)

RAG-basierte KI-Anwendung mit NLP-Pipeline, semantischer Suche und FastAPI-Backend zur kontextbezogenen Wissensabfrage.
**Stack:** Python, LangChain, FastAPI, ChromaDB, Docker.

### 📖 [Lianes Library](https://github.com/jeorgesilva/lianes-library)

KI-gestütztes Bibliothekssystem mit SQL-Datenbank, semantischer Suche und NLP-basierten Empfehlungssystemen.
**Stack:** Python, SQL, NLP, semantische Suche, Sentimentanalyse.
